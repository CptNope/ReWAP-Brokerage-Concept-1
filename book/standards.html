9.1

Accessibility: WCAG 2.2 AA

A launch requirement, tested on the search and listing flows first because they are the hardest.

  • KeyboardEvery control reachable and operable in a logical order; visible 2 px focus everywhere (2.4.7, 2.4.11). Skip link on every page.
  • Dialogs and sheetsNative <dialog> where possible; focus moves in, is contained, Escape closes, focus returns to the trigger.
  • SearchCombobox pattern for location suggestions; result-count changes announced with a polite live region; the list is the accessible equivalent of the map.
  • FormsVisible labels, autocomplete tokens, errors linked with aria-describedby and summarised at the top on submit (3.3.1–3.3.3). No CAPTCHA puzzles (3.3.8).
  • TargetsAt least 44 × 44 px; never below the 24 × 24 px minimum (2.5.8). Dragging on the map always has a non-drag alternative (2.5.7).
  • ContrastPairs from 3.6 only. Text on photographs only over a solid field.
  • MediaListing photos get alt text from room and feature data (“Kitchen with gas range and window over the sink”), never “image 1.” Virtual tours offer a text summary.
  • MotionReduced-motion respected (8.5); nothing flashes; no auto-advancing content.

9.4

IDX adapter contract

Templates read only this shape. A new vendor means one new adapter class, not new templates. Field names follow the RESO Data Dictionary where one exists.

interface ListingProvider {
  search(query: ListingQuery): Promise<Page<Listing>>;
  get(listingKey: string): Promise<Listing | null>;
  openHouses(range: DateRange, area?: AreaRef): Promise<OpenHouse[]>;
  areas(prefix: string): Promise<AreaRef[]>;       // towns, neighborhoods, ZIPs
  attribution(listing: Listing): Attribution;     // MLS + listing office text, logo rules
  freshness(): Promise<{ updatedAt: string }>;    // shown on every results view
}

type Listing = {
  listingKey: string; mlsNumber: string;
  status: 'Active' | 'ActiveUnderContract' | 'Pending' | 'Closed' | 'ComingSoon';
  listPrice: number; closePrice?: number;
  address: { street: string; unit?: string; city: string; state: 'MA'; postalCode: string };
  geo?: { lat: number; lng: number };
  propertyType: 'Residential' | 'MultiFamily' | 'Condo' | 'Land' | 'Commercial';
  bedrooms?: number; bathroomsTotal?: number; livingArea?: number; lotSizeAcres?: number;
  yearBuilt?: number; units?: number; taxAnnual?: { amount: number; year: number };
  media: { url: string; width: number; height: number; caption?: string }[];
  remarks?: string;
  listOffice: { name: string; id: string }; listAgent?: { name: string; id: string };
  isOwnListing: boolean;   // true when listOffice is REWAP or an affiliated team
  updatedAt: string;
};

9.8

WordPress translation

The production site is a block theme. This book maps onto it directly, with native features first and the fewest plugins possible.

  • theme.jsonPalette, type scale, spacing and layout widths from tokens/theme.json (draft). Editors pick only from the palette.
  • PatternsEach composition in 6.4 and component in chapter 7 becomes a locked block pattern: Index, Plate, Statement, Catalogue, Ledger, CTA.
  • Content typesCustom post types for Person, Team, Community and Market Update; taxonomies for Region and Town. Listings stay in the IDX layer, cached, not as posts.
  • IDXThe vendor plugin supplies data only; its widgets are not used. A small REWAP plugin implements the adapter (9.4) and renders with the theme’s blocks.
  • HostingCloudways, with page caching for content and short-lived object caching for listing queries.
9.9

Compliance surfaces

Designed in from the start, styled as content (7.10), and reviewed by Hong Tran before launch. This list is a checklist, not legal advice.

  • Agency disclosureThe Massachusetts Mandatory Licensee-Consumer Relationship Disclosure, linked from every contact point.
  • Fair HousingEqual Housing Opportunity statement and logo in the footer; language rules in 1.9 and 5.1.
  • MLS display rulesListing office attribution, data-currency notice and disclaimer on every listing view, per the MLS’s IDX rules.
  • Brokerage identificationLegal name and office address on every page.
  • PrivacyPrivacy policy, consent before non-essential analytics, clear opt-in for listing alerts and texts.
  • Accessibility statementPublished with a contact route for problems.
